# Captures d’écran à prendre (Overleaf)

Crée un dossier `figures/` dans ton projet Overleaf (au même niveau que `report_v1.0.tex`).

Prends les captures dans le navigateur (fenêtre claire, sans onglets inutiles), puis renomme-les **exactement** comme ci-dessous.

| Fichier | Quoi capturer |
|---------|----------------|
| `01_accueil.png` | Page d’accueil (hero + boutons Découvrir / Se connecter) |
| `02_inscription.png` | Formulaire Créer un compte |
| `03_connexion.png` | Écran Se connecter |
| `04_bibliotheque.png` | Bibliothèque enfant (cartes d’histoires) |
| `05_profil.png` | Mon profil (langues maternelle / cible visibles) |
| `06_import_admin.png` | Espace admin avec bouton Importer (ou dialogue d’import) |
| `07_admin.png` | Tableau de bord administrateur |
| `08_lecteur.png` | Lecteur d’une histoire (texte + boutons visibles) |
| `09_quiz.png` | Quiz / discussion IA (mode Écrire) |
| `10_quiz_oral.png` | Quiz en mode Parler (micro visible) |

Tant qu’un fichier manque, le PDF affiche un **cadre gris** « Capture à ajouter » à la place de l’image — le document compile quand même.
